# SMP-Stats 1.0.0 (author: Kaloyan)
Counts kills, deaths, mobs killed, blocks mined and playtime. `/leaderboard` (aliases /lb, /top) opens a menu of boards (money, kills, deaths, playtime, blocks, mobs,
shards) with the top 10 as player heads and your own place; shortcuts `/baltop /killtop /deathtop /playtop /blocktop /mobtop /shardtop`. `/stats [player]` shows a summary.
Money and shards are read every 5 minutes. Data: `stats.yml` (atomic writes; a damaged file stops the plugin). Needs SMP-Core and SMP-Economy (SMP-Shop optional).
