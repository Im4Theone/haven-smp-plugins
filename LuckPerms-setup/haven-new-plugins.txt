# Run these in the console (or in game as op) AFTER "lp import haven". They add the new plugins to your ranks.
# Safe to run more than once, and safe to run on a server that already ran an older version of this file (the last block cleans up).
#
# RULE: every staff command (ban, banlist, kick, mute, warn, history, trap, v, freeze, kitadmin, eco, smpcore, protect, drill, spawners,
# ordersadmin, keyall, setspawn, havenbuild, ...) belongs to GUARDIAN (admin) ONLY. Founder inherits Guardian. Nobody else gets those
# permissions, so nobody else sees those commands (they are hidden from the command list and from tab-complete).
# Everybody sees /kit, /shop, /ah, /order, /crates, /rtp, /home, /spawn, /hub, /tpa, /back, /worth, /balance, /pay, /shards.

# ---- Homes: Wanderer 1 (default), Settler 2, Keeper 3, Beacon 5, Lookout 7, Warden 10, Guardian unlimited ------------------------
lp group settler permission set smptravel.homes.2 true
lp group keeper permission set smptravel.homes.3 true
lp group beacon permission set smptravel.homes.5 true
lp group lookout permission set smptravel.homes.7 true
lp group warden permission set smptravel.homes.10 true
lp group guardian permission set smptravel.homes.unlimited true

# ---- Auction house listing limits (everybody sees /ah) ---------------------------------------------------------------------------
lp group settler permission set smpauction.limit.10 true
lp group keeper permission set smpauction.limit.25 true
lp group beacon permission set smpauction.limit.50 true

# ---- Kits: one kit per rank. Everybody sees /kit; Guardian (admin) gets none, the Founder plays and gets them all ----
# Ranks inherit the kits of the ranks below them (a Beacon can claim Wanderer + Settler + Keeper + Beacon).
# Wanderer = every player without a rank (the default group). All ranks inherit it.
lp group default permission set smpkits.kit.wanderer true
lp group settler permission set smpkits.kit.settler true
lp group keeper permission set smpkits.kit.keeper true
lp group beacon permission set smpkits.kit.beacon true
lp group lookout permission set smpkits.kit.lookout true
lp group warden permission set smpkits.kit.warden true
# Guardian (admin): no kits (a node on the group itself beats what it inherits).
lp group guardian permission set smpkits.kit.wanderer false
lp group guardian permission set smpkits.kit.settler false
lp group guardian permission set smpkits.kit.keeper false
lp group guardian permission set smpkits.kit.beacon false
lp group guardian permission set smpkits.kit.lookout false
lp group guardian permission set smpkits.kit.warden false
# Founder plays too: the kits are switched back on for the Founder (the group's own nodes beat the false ones inherited from Guardian).
lp group founder permission set smpkits.kit.wanderer true
lp group founder permission set smpkits.kit.settler true
lp group founder permission set smpkits.kit.keeper true
lp group founder permission set smpkits.kit.beacon true
lp group founder permission set smpkits.kit.lookout true
lp group founder permission set smpkits.kit.warden true
# (SMP-Kits also checks the main rank itself, so Guardian is refused even if a node slips through.)

# ---- Staff commands: GUARDIAN only (Founder inherits) ----------------------------------------------------------------------------
